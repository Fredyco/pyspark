CODA Phase 2 · Batch Processing

pandas ↔ PySpark

Padanan sintaks pandas 2.x dan PySpark 4, ditambah hal-hal penting yang hanya ada di Spark. Contoh memakai data Superstore dengan nama kolom snake_case (order_id, sales, region, customer_id, …), sama seperti notebook 01_pandas_vs_spark. Kode PySpark mengasumsikan from pyspark.sql import functions as F.

Beda cara berpikir

Eksekusi

pandas
Eager: tiap baris langsung dihitung.
PySpark
Lazy: transformasi dicatat, baru jalan saat action (show, count, write).

Mengubah data

pandas
Bisa diubah langsung: df["x"] = …, inplace=True.
PySpark
Immutable: selalu simpan ulang, df = df.withColumn(…).

Lokasi data

pandas
Semua di RAM satu komputer.
PySpark
Dipecah ke partisi, diproses paralel (bisa banyak mesin).

Index & urutan

pandas
Punya index; urutan baris terjaga.
PySpark
Tidak ada index; urutan tidak dijamin tanpa orderBy.

Tidak ada sintaks yang cocok. Coba kata lain, misalnya filter atau agg.

Jebakan yang sering muncul

  1. Lupa escape='"' saat membaca CSV yang teksnya berisi koma & tanda kutip: kolom bergeser dan angka terbaca string. Selalu cek printSchema().
  2. df.withColumn(…) tanpa df = … tidak mengubah apa-apa, karena DataFrame Spark immutable.
  3. df.head(5) di Spark mengembalikan list of Row, bukan tabel. Untuk melihat data pakai df.show(5).
  4. Jumlah baris bertambah setelah join = tabel kanan punya ID duplikat. Jalankan dropDuplicates(['id']) sebelum join, dan bandingkan count() sebelum & sesudah.
  5. Format tanggal berbeda: pandas "%m/%d/%Y", Spark "M/d/yyyy" (MM = bulan, mm = menit).
  6. write.jdbc(..., mode="overwrite") menghapus tabel buatan DDL beserta primary & foreign key. Untuk tabel yang dibuat dengan SQL, pakai mode="append".
  7. Load fact sebelum dimension → error foreign key. Selalu load dimension dulu.
  8. Host PostgreSQL: dengan conda, notebook jalan di laptop → localhost. Dengan Docker, localhost = container itu sendiri → pakai host.docker.internal.
  9. df.write.csv("out") menghasilkan folder berisi file part-*, bukan satu file.
  10. toPandas() menarik semua data ke memori laptop. Lakukan setelah data diagregasi atau difilter.
  11. Kondisi gabungan wajib diberi kurung: (a > 1) & (b == 2). Pakai &, |, ~, bukan and/or/not.
